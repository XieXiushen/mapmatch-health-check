方法与纪律

数据管道

  1. 归档原文到 raw/（URL 只归档，不改写、不解析）；tools/collect/sources.json 登记 slug→URL。
  2. 抽取：tools/collect/extract.py 对 raw/*.html 去标签 + 关键词过滤，落 temp/digest.txt 供人工核对（不做数值改写）。
  3. 回填：人工核对后写入 data/chips/*.json；每字段 source_url 指回 raw/ 已归档来源。
  4. 校验：tools/validate.py（详见下）。
  5. 渲染：tools/build.py 仅渲染通过校验的卡片。

校验规则

R1 结构(≥25 字段且六键齐全)；R2 非空；R3 日期格式；R4 置信枚举；R5 来源可追溯(source_url 命中 sources.json 且 raw/<slug>.html 存在)；R6 数字字段必须带单位；R7 冲突登记完整且 conflict_with 可追溯。

边界：校验器保证“已登记项的完整与可追溯”，不保证“冲突发现的覆盖度”——后者依赖人工检索登记，属已知局限。

口径说明

source_date 对动态产品页/规格站取「归档取得日」(2026-10-09)；对安全可靠认证公告取「公告发布日」(2026-05-26)。confidence: verified=≥2 个已归档来源一致；single-source=单一已归档来源；unverified=公开口径未给出（值为“未公开”）。

GEO 引用层（r41）

  1. robots.txt：对 9 个 AI/检索直取器（GPTBot / ChatGPT-User / ClaudeBot / PerplexityBot 等）逐条显式 Allow；对 5 个 SEO/反链采集器（AhrefsBot / SemrushBot 等）Disallow；并附 Sitemap 指令。
  2. sitemap.xml：由构建器按实际页面树生成，<loc> 条数 = 页面数（见页脚构建号与本页 [6] 核对）。
  3. dataset/chips.json：开放数据集导出（单一事实源 = data/chips/*.json），许可 CC BY 4.0；引用格式见 数据集页。
  4. 字段级 SEO：每页 <title>/<meta description> 由数据生成；型号页另含数据推导的 <meta keywords>（源自 data/chips/*.json 的 keywords 字段）。

量口径唯一来源：型号数、厂商数、字段数均取自 data/chips/*.json，页面内数字一律由构建器注入，不手写。
